# 📚 Telegram Quiz Bot

एक पूरी तरह से कार्यात्मक क्विज़ बॉट – क्विज़ बनाएँ, खेलें, रिजल्ट देखें।

## ✨ फीचर्स
- ✅ क्विज़ क्रिएशन (टाइटल, विवरण, निर्देश, MCQs)
- ✅ टाइमर (ग्लोबल / फास्ट मोड)
- ✅ मार्किंग (पॉजिटिव / नेगेटिव)
- ✅ HTML रिजल्ट रिपोर्ट
- ✅ यूज़र मैनेजमेंट
- ✅ एडमिन पैनल
- ✅ ब्रॉडकास्ट
- ✅ MongoDB बैकअप

## 🛠️ डिप्लॉयमेंट
1. `.env` फाइल बनाएँ और सभी वेरिएबल डालें।
2. `pip install -r requirements.txt`
3. `python -m bot.main` (या Render/Heroku पर डिप्लॉय करें)

## 📌 कमांड्स
- `/start` – बॉट शुरू करें
- `/newquiz` – नई क्विज़ (एडमिन)
- `/editquiz` – क्विज़ एडिट
- `/postquiz` – पब्लिश
- `/setquiztime` – टाइमर सेट
- `/fast20`, `/fast15` – फास्ट मोड
- `/broadcast` – मैसेज भेजें (एडमिन)
- `/userlist` – यूज़र लिस्ट
- `/admins` – एडमिन लिस्ट
- `/addadmin`, `/deladmin` – एडमिन प्रबंधन

## 🧑‍💻 टेक स्टैक
- Python 3.11
- Pyrogram
- Motor (MongoDB)
- Jinja2
